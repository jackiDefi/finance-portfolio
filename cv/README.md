# CV folder

Drop your CV here as **`cv.pdf`** (lowercase, exactly that filename).

The site links to `cv/cv.pdf` from:
- The top-nav "CV" link on every page
- The "Download CV (PDF)" button on `about.html`
- The CV card pattern on the homepage (indirect)

If you rename the file or use a different format, update the links in:
- `index.html`
- `about.html`
- Every page under `industries/*/index.html`

Tip: keep the file under ~1.5 MB so it loads instantly. Export from Word/Pages with "best for electronic distribution" rather than "best for printing".
